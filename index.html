About Me

Vincent Mutei Mutinda

I'm a Software Engineer who builds the part of the stack users never see — the APIs, database schemas, pipelines and deployment plumbing that make an application actually work.

My core is backend development: JavaScript and Node.js with Express, designing RESTful APIs for business applications, data exchange and system integrations. I work daily with both relational and NoSQL databases — SQL and MongoDB — with a focus on integrity, ACID transaction properties and reliable data operations.

Alongside application work, I build small-to-medium data warehouses for SMEs using the Medallion Architecture (Bronze, Silver, Gold), handle data modelling, and ship Power BI dashboards that translate operational and financial data into KPIs business owners can act on.

I deploy and maintain what I build on AWS with Git and CI/CD workflows, and I bring a working knowledge of IT infrastructure, networking and cybersecurity — from enterprise helpdesk support at Nairobi City Water and Sewerage Company to first-line IT at Keight Wellness.

"Build the API cleanly, model the data honestly, and the reports take care of themselves."
